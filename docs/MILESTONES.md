# 开发里程碑

这份记录从 iPad 适配开始，记录到第一个公开基线。三端移植能力来自上游 [PvZ-Portable](https://github.com/wszqkzqk/PvZ-Portable)。

| 阶段 | 做了什么 |
| --- | --- |
| 移动端启动与触摸 | 接入 iOS 单窗口场景，处理前后台切换中断的触摸，修正横屏坐标，并调整音频准备流程。 |
| 昵称输入 | 修复键盘唤起后卡住的问题，让输入框和操作按钮在 iPad 上避开键盘。 |
| 对局设置 | 加入自动收阳光和四档调速，设置跨关卡和重启保留。 |
| 冒险重玩与星级 | 为原有五章五十关加入选关页，分开主线和重玩存档，增加逐关星级结算、最高分记录和新星点亮动画。 |
| 收金币与生命显示 | 加入自动收金币和显示生命，植物满血时隐藏血条。新选项沿用原来的石板样式。 |
| 再战防守 | 在三星记录之外加入金色标记。完成首轮冒险后重新开局，未触发救场车通关即可获得，旧记录不补算。 |
| 三端测试版 | iPhone 和 iPad 共用移动版，分别在真机上安装启动。Mac 单独制作可双击的原生测试包，重新编译游戏和依赖至 macOS 13.3 目标。 |

基线验收范围见 [README](../README.md#验证范围)。
